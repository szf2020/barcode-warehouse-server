# SoftSnail 倉管系統 — 使用者手冊

## 登入系統

1. 開啟瀏覽器，輸入系統網址（由管理員提供）
2. 輸入帳號、密碼
3. 點擊「登入」

> 如忘記密碼，請聯繫系統管理員重設。

---

## 功能總覽

| 功能 | 說明 |
|------|------|
| 庫存 | 查看所有商品的即時庫存數量 |

## 庫存

查看目前所有商品的庫存狀況。

- **搜尋**：在搜尋框輸入條碼、品名、規格等關鍵字
- **新增品項**：點「新增品項」填寫條碼、品名、規格、儲位等資訊
- **編輯**：點品項右側的✏️圖示修改資料
- **刪除**：點🗑️圖示刪除品項

> 庫存數量會由進貨收貨（+）和銷貨出貨（-）自動計算，不需手動修改。

---

## 客戶管理

建檔購買商品或送修的客戶。

1. 點「新增客戶」
2. 編號會自動產生（C001, C002...），也可手動修改
3. 填寫客戶名稱、聯絡人、電話、地址等
4. 點「建立」

---

## 供應商管理

建檔進貨的供應商。

1. 點「新增供應商」
2. 編號自動產生（S001, S002...）
3. 填寫供應商名稱、聯絡人、電話、匯款帳號等
4. 點「建立」

---

## 進貨作業

向供應商採購商品。

### 建立進貨單

1. 進入「進貨」→ 點「新增進貨單」
2. 選擇供應商、填寫日期
3. 點「建立」

### 加入商品明細

1. 在進貨單詳情頁，使用掃碼槍掃描條碼，或從下拉選單選擇品項
2. 填入數量、單價
3. 點「+」加入

### 確認進貨單

- 點「確認」→ 系統自動產生應付帳款（代表你欠供應商的錢）

### 收貨入庫

- 點「收貨入庫」→ 庫存數量自動增加

---

## 報價作業

對客戶提供報價。

### 建立報價單

1. 進入「報價」→ 點「新增報價單」
2. 選擇客戶、填寫日期、有效期限
3. 加入品項明細（品項、數量、報價單價）

### 狀態操作

- **送出**：報價單送給客戶
- **接受**：客戶同意報價 → 可一鍵轉為銷貨單
- **拒絕**：客戶不接受

---

## 銷貨作業

出貨給客戶。

### 建立銷貨單

方法一：從已接受的報價單，點「轉為銷貨單」自動帶入所有品項  
方法二：手動新增銷貨單，選客戶後逐項加入

### 操作流程

1. **確認** → 產生應收帳款（客戶欠你的錢）
2. **出貨扣庫** → 庫存數量自動減少
3. **完成** → 此筆交易結案

---

## 帳務管理

### 帳務總覽

顯示目前未結清的應收/應付金額、逾期筆數。

### 應收帳款（客戶欠你的）

- 銷貨單確認時自動產生
- 點「+」按鈕記錄收款（現金/匯款/支票）
- 收足金額後自動標記「已結清」

### 應付帳款（你欠供應商的）

- 進貨單確認時自動產生
- 點「+」按鈕記錄付款
- 付足金額後自動標記「已結清」

---

## 維修工單

追蹤客戶送修商品的維修進度。

### 收件

1. 進入「維修」→ 點「新增工單」
2. 選擇客戶，填寫送修品名、品牌、型號、序號
3. 描述故障狀況
4. 點「建立」

### 狀態追蹤

依實際進度點擊狀態按鈕：

```
收件 → 檢測中 → 維修中 → 完工 → 客戶取件
                  ↓
              等零件（零件到貨後回到維修中）
```

### 費用計算

- 填寫維修說明和工資
- 新增使用的零件（名稱、數量、單價）
- 系統自動計算：**總費用 = 工資 + 零件費**

## 常見問題

**Q：庫存數量怎麼改？**  
A：不需要手動改。進貨收貨會自動加，銷貨出貨會自動減。如需手動調整，可透過掃碼器掃碼入庫/出庫。

**Q：報價單怎麼變成銷貨單？**  
A：報價單被客戶接受後，點「轉為銷貨單」按鈕即可，所有品項和價格會自動帶入。

**Q：怎麼知道客戶還欠多少錢？**  
A：進入「帳務」→「應收帳款」，可以看到每筆未結清的金額和餘額。

**Q：維修完成怎麼通知客戶？**  
A：維修單狀態改為「完工」後，可列印完工通知單給客戶。

**Q：可以用手機操作嗎？**  
A：可以。系統使用 RWD 設計，手機瀏覽器開啟網址即可使用。
