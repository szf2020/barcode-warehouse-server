## 採購建議

### 推薦購買平台
- **露天/蝦皮** — ESP32 開發板、感測器模組
- **台灣物聯** — ESP32-S3 原廠開發板
- **ICShop / 光華商場** — 被動元件、排線、麵包板
- **AliExpress** — OV2640 模組、TFT 螢幕（價格最低但需等待）

### 注意事項
1. ESP32-S3 務必選 **N16R8** 版本（16MB Flash + 8MB PSRAM），攝影機需要大量 RAM
2. OV2640 模組選擇 **24-pin FPC 排線** 版本，確認排線長度足夠
3. TFT LCD 確認是 **SPI 介面**（非 8080 並列），且 3.3V 邏輯相容
4. MicroSD 模組選 **3.3V 相容**版本，ESP32-S3 IO 為 3.3V
5. USB 線確認有**數據功能**（非純充電線），用於燒錄韌體
